Every run saves the first and last pre-game price and model probability for each outcome in this browser. Settling grades props from ESPN game logs and moneylines from ESPN final scores. The model has an edge only if its Brier score beats the AU market's and calibration is flat (observed ≈ predicted). CLV = closing fair prob × first price − 1; consistently positive CLV is the earliest sign of a real edge. Each player/market/side counts once (its main line), and results within a game move together, so expect noisy numbers until you have a few hundred games. Export regularly: browser storage can be cleared.
